# #share-tech resources — week of 12–19 Nov 2026

7 curated resources, newest first.

## Dukoi
- URL: https://dukoi.com/
- Shared by: thelaggingway (13 Nov)
- Categories: dev-tool, web-app
- Brief: Dukoi turns a spare Android phone into a server — install the app, pair it with the CLI over Wi-Fi, and deploy real apps that get a live URL, with no root, no Termux, and no cloud bill. It runs apps as a foreground service that restarts them within seconds if Android kills them, works behind CGNAT with optional custom domains via Cloudflare, and keeps every deploy as a rollback-able release with live logs in the terminal and dashboard.

## Zeron
- URL: https://zeron.sh/
- Shared by: ROman (14 Nov)
- Categories: ai-tool, dev-tool
- Brief: Zeron is a native desktop app for driving the coding agents already on your machine — Claude Code, Codex, Cursor, Grok, Hermes, and Pi — from any of your devices, with sessions living on your machines and every device able to pilot them. Start a session at your desk, watch it from your phone, and approve diffs from the couch, with plugins and a chart-drawing reply view built in.

## DesignBookmark Motion
- URL: https://designbookmark.com/motion
- Shared by: Tom (15 Nov)
- Categories: web-app, dev-tool
- Brief: DesignBookmark Motion is a gallery of animated UI components running live in the browser — springy inputs, morphing tooltips, jelly sliders, swipe decks and more — each with copyable code for Claude or Codex. Pick a motion you like, paste it into your project, and your AI coder builds it for you, so vibe-coded sites stop looking flat.

## pi-better
- URL: https://github.com/nicobailon/pi-better
- Shared by: simply_roo (15 Nov)
- Categories: dev-tool, github
- Brief: pi-better is a Pi extension that rewrites your prompts before you send them — type /better and a forked subagent reads your code in the background, then applies Felix Rieseberg's "Depth" prompt to produce a sharper version grounded in your actual files. The improved prompt lands in your input box for review, and your agent can use it on subagent briefs too. MIT-licensed, 104 stars, installs with `pi install npm:pi-better`.

## baum
- URL: https://github.com/baum-ai/baum
- Shared by: Tom (15 Nov)
- Categories: ai-tool, dev-tool
- Brief: baum is a desktop app that sits on top of your coding agents — it reviews the pull requests in your GitHub repos, shows which Claude Code and Codex sessions need you, and links every change back to the sessions and decisions behind it. Everything runs locally with no baum account or server, and reviews run through your own Claude Code or Codex. MIT-licensed, desktop app for macOS and Linux.

## Yab
- URL: https://github.com/yetanotherbrowser/yab
- Shared by: Tom (15 Nov)
- Categories: dev-tool, github
- Brief: Yab is a fast native macOS browser — now fully open-source, with iPhone and Android companions — pitched as the best Arc alternative, with tabs across the top or down the left, spaces, and a single address/search field. Pages run on WebKit or, on Apple silicon, Chromium per tab, with a built-in ad blocker, reading mode, split view, and agents that work in their own tabs without seeing private ones. Apache-2.0, 336 stars.

## Tern
- URL: https://stencil.so/tern
- Shared by: simply_roo (17 Nov)
- Categories: dev-tool
- Brief: Tern is a Rust-native terminal from Stencil whose sessions outlive the window — shells, omp and browser panes keep running in a daemon, shared live across Mac, iOS and a WebGPU browser tab, with git, SQLite, Jupyter, kanban, task-manager and screen-sharing blocks beside them. It draws your omp theme and powerlevel10k prompt natively, opens in 151 ms with no bundled Chromium, and is in closed beta behind a waitlist. The 151 ms startup claim is vendor-reported and unverified.
