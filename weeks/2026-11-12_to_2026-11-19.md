## Dukoi
- URL: https://dukoi.com/
- Shared by: thelaggingway (13 Nov)
- Categories: dev-tool, web-app
- Brief: Dukoi turns a spare Android phone into a server — install the app, pair it with the CLI over Wi-Fi, and deploy real apps that get a live URL, with no root, no Termux, and no cloud bill. It runs apps as a foreground service that restarts them within seconds if Android kills them, works behind CGNAT with optional custom domains via Cloudflare, and keeps every deploy as a rollback-able release with live logs in the terminal and dashboard.

## Zeron
- URL: https://zeron.sh/

- Categories: ai-tool, dev-tool
- Brief: Zeron is a native desktop app for driving the coding agents already on your machine — Claude Code, Codex, Cursor, Grok, Hermes, and Pi — from any of your devices, with sessions living on your machines and every device able to pilot them. ## pi-better
- URL: https://github.com/nicobailon/pi-better
- Shared by: simply_roo (15 Nov)
- Categories: dev-tool, github
- Brief: pi-better is a Pi extension that rewrites your prompts before you send them — type /better and a forked subagent reads your code in the background, then applies Felix Rieseberg's "Depth" prompt to produce a sharper version grounded in your actual files. The improved prompt lands in your input box for review, and your agent can use it on subagent briefs too. MIT-licensed, 104 stars, installs with `pi install npm:pi-better`.

## baum

## Yab

## Tern

## Agent Substrate
- URL: https://github.com/agent-substrate/substrate

- Categories: ai-tool, dev-tool, github
- Brief: Agent Substrate is a zero-trust runtime for running millions of sandboxed agents on Kubernetes, isolating each agent in a microVM or gVisor sandbox with its own identity, storage and default-deny networking, and resuming idle agents from snapshots in under 500 ms — about 250 stateful actors multiplexed onto 8 pods at 10x the density of plain containers. ## Energy-Based Reasoners
- URL: https://arxiv.org/abs/2611.08977
- Shared by: Tom (18 Nov)
- Categories: article
- Brief: Energy-Based Reasoners is a paper from Chen, Gladstone and colleagues that treats looped reasoning as gradient descent on a learned energy function over latent reasoning states, giving the model an explicit sense of progress and a stopping signal. Across four algorithmic reasoning benchmarks it matches or beats prior looped models, hitting 99.9% on Sudoku-Extreme with 345x less inference compute than the next-best model.

## Distortion Waves
- URL: https://libraries.dev/waves
- Shared by: Tom (18 Nov)
- Categories: dev-tool
- Brief: Distortion Waves is a free, open-source, MIT-licensed screen-transition library for React and SwiftUI that carries one view into another on a colourful wave opening from the button, edge or avatar that started it, with edge glows, chromatic aberration, particles and anticipation movement. Install it with npm install distortion-waves (React 18+, WebGL2) or Swift Package Manager (DistortionWavesKit, iOS 17+), with vertical, horizontal and centre wave types and six palettes.

## Redis Iris

- Categories: ai-tool, dev-tool
- Brief: Redis Iris is Redis's real-time engine for giving AI agents the memory, context and messaging they need, bundling six capabilities — Intent Router, Agent Playbooks, Agent Memory, Context Gateway, Lens and Agent Mesh — into one system.
