# #share-tech resources — week of 19–26 Nov 2026

10 curated resources, newest first.

## Elephant-Goldfish Model
- URL: https://egm.dev/
- Shared by: ROman (20 Nov)
- Categories: ai-tool, dev-tool
- Brief: The Elephant-Goldfish Model (EGM) is an open-source plugin for AI assistants that splits plan drafting from plan review: one assistant that knows the full background helps you write the plan, then fresh reviewers who never saw the conversation read only the plan and report what is missing or unclear. It runs in supported AI assistant apps with no coding needed, and the method comes from Dave Rensin's "Elephants, Goldfish, and the New Golden Age of Software Engineering".

## UniXNU
- URL: https://github.com/UniXNU/UniXNU
- Shared by: Tom (20 Nov)
- Categories: dev-tool, github
- Brief: UniXNU is an open-source UEFI environment that boots iOS and macOS on non-Apple ARM64 hardware, in the spirit of OpenCore: it loads the drivers a device needs and boots the OS through a common UEFI layer. It ships shared build tools, ARM64 support, OS profiles and reusable components, with device ports (such as Xiaomi Pad 6S Pro) maintained in separate repos and docs at unixnu.com.

## a2ui
- URL: https://github.com/a2ui-project/a2ui
- Shared by: ROman (22 Nov)
- Categories: ai-tool, github
- Brief: a2ui is an open-source generative UI framework for AI agents: agents stream layout data and apps render it with native components instead of screenshots or HTML. It ships renderers for React, Angular, Lit, Flutter, SwiftUI and Jetpack Compose, with a shared component catalogue and a protocol for agent-driven layouts.

## wland
- URL: https://github.com/pithings/wland
- Shared by: simply_roo (22 Nov)
- Categories: dev-tool, github
- Brief: wland is an open-source Wayland compositor that runs entirely in the browser, written in Zig and compiled to WebAssembly at roughly 65 kB gzipped. It composites Wayland apps at up to 120 FPS with pixel-perfect Retina rendering, so native Linux GUI apps can run inside a web page with no server.

## OpenUI Live Replies
- URL: https://getbb.app/marketplace/openui
- Shared by: ROman (22 Nov)
- Categories: ai-tool
- Brief: OpenUI Live Replies is a plugin for the bb coding agent that turns agent replies into dashboards, reports, plans and forms you can read at a glance and click, right in the chat. Agents write OpenUI Lang and the plugin renders it with OpenUI's React component library plus about 70 of its own components — gauges, heatmaps, timelines, kanban boards, test and coverage reports, diffs and maps.

## Gemini Frontend Design
- URL: https://github.com/google-gemini/demolab
- Shared by: Alp (25 Nov)
- Categories: ai-tool, github
- Brief: An agent skill from Google's Gemini team that teaches coding agents to build fast, clean landing pages with Gemini 4 Neon, built around five anti-slop rules — full-bleed display type, at most two font families, subject-matched colour palettes, custom Nano Banana visuals, and no pill badges, eyebrow kickers or nested cards. Install it with `npx skills add https://github.com/google-gemini/demolab --skill gemini-frontend-design` and it works with any agent that supports the open Agent Skills format, including Claude Code, Cursor and Gemini CLI.

## BlackBox Arena
- URL: https://blackboxarena.ai/
- Shared by: scarywood75 (24 Nov)
- Categories: ai-tool, web-app
- Brief: BlackBox Arena (BB Arena) is an AI security benchmarking site that tests models across 100 black-box web and API security labs using a four-rung proof ladder and a single neutral harness. Alongside model leaderboards, it also publishes side-by-side provider comparison boards (such as DeepSeek V4.1 Flash) tracking solve rate, speed, timeouts, tokens, and cost per solve.

## pi-durable-bot (Pots)
- URL: https://github.com/Crokily/pi-durable-bot
- Shared by: Thoor (25 Nov)
- Categories: ai-tool, github
- Brief: Pots is a self-hosted, open-source AI coworker (MIT) that reads the channels you give it — Slack, Discord, Telegram, Teams — decides what matters, and does the work on its own computer instead of just answering when mentioned. Built on pi-durable, it runs any model you choose — a subscription login, an API key from 40+ providers, or a local model — and each bot keeps its own name, persona, responsibilities, and memory.

## Gemini API CLI
- URL: https://github.com/google-gemini/gemini-api-cli
- Shared by: Blessed Piss Enjoyer (26 Nov)
- Categories: ai-tool, github
- Brief: Google's experimental CLI for the Gemini API (Apache-2.0) gives coding agents and shell scripts a single binary for Gemini text and reasoning models, multimodal file analysis, and image, audio, music, and video generation. Configure an API key, put `gemini-api` on PATH, and any agent with shell access can generate assets, analyze files, or launch a managed agent in the background and pick up the result later.

## Vals AI

- Categories: ai-tool, web-app
