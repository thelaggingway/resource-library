## Elephant-Goldfish Model
- URL: https://egm.dev/
- Shared by: ROman (20 Nov)
- Categories: ai-tool, dev-tool
- Brief: The Elephant-Goldfish Model (EGM) is an open-source plugin for AI assistants that splits plan drafting from plan review: one assistant that knows the full background helps you write the plan, then fresh reviewers who never saw the conversation read only the plan and report what is missing or unclear. It runs in supported AI assistant apps with no coding needed, and the method comes from Dave Rensin's "Elephants, Goldfish, and the New Golden Age of Software Engineering".

## UniXNU
- URL: https://github.com/UniXNU/UniXNU
- Shared by: Tom (20 Nov)
- Categories: dev-tool, github
- Brief: UniXNU is an open-source UEFI environment that boots iOS and macOS on non-Apple ARM64 hardware, in the spirit of OpenCore: it loads the drivers a device needs and boots the OS through a common UEFI layer. It ships shared build tools, ARM64 support, OS profiles and reusable components, with device ports (such as Xiaomi Pad 6S Pro) maintained in separate repos and docs at unixnu.com. - Warning: early-stage project — the repo was created in October 2026 and the channel discussion notes it is not yet ready, with porting described as a real pain.

## a2ui
- URL: https://github.com/a2ui-project/a2ui
- Shared by: ROman (22 Nov)
- Categories: ai-tool, github
- Brief: a2ui is an open-source generative UI framework for AI agents: agents stream layout data and apps render it with native components instead of screenshots or HTML. It ships renderers for React, Angular, Lit, Flutter, SwiftUI and Jetpack Compose, with a shared component catalogue and a protocol for agent-driven layouts.

## wland
- URL: https://github.com/pithings/wland
- Shared by: simply_roo (22 Nov)
- Categories: dev-tool, github
- Brief: wland is an open-source Wayland compositor that runs entirely in the browser, written in Zig and compiled to WebAssembly at roughly 65 kB gzipped. It composites Wayland apps at up to 120 FPS with pixel-perfect Retina rendering, so native Linux GUI apps can run inside a web page with no server. - Warning: announced 21 Nov 2026 — very early project, expect rough edges.

## OpenUI Live Replies
- URL: https://getbb.app/marketplace/openui
- Shared by: ROman (22 Nov)
- Categories: ai-tool
- Brief: OpenUI Live Replies is a plugin for the bb coding agent that turns agent replies into dashboards, reports, plans and forms you can read at a glance and click, right in the chat. Agents write OpenUI Lang and the plugin renders it with OpenUI's React component library plus about 70 of its own components — gauges, heatmaps, timelines, kanban boards, test and coverage reports, diffs and maps. - Warning: requires BB 0.49 or later; web lookups are on by default and share your IP with OpenStreetMap, Photon, Wikipedia and Wikimedia Commons unless turned off.
