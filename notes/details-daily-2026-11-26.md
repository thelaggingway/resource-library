## Details

### pi-durable-bot-pots
- Details: Pots (pi-durable-bot) is an open-source, MIT-licensed AI coworker that lives in the chat tools a team already uses — Slack, Discord, Telegram, and Microsoft Teams in preview — and acts on its own computer rather than only answering when mentioned. It reads every channel, email, and event it is given, decides what matters, does the work (checking a page, sending a comparison, taking an API key on a one-time page), and speaks up when it should; it can also run several bots on one machine, each with its own name, persona, responsibilities, and memory, and a bot can even edit its own definition or create a new bot. It is built on pi-durable, so it works with any model: a subscription login, an API key from any of the 40+ providers pi supports, an OpenAI-compatible endpoint, or a local model via Ollama, LM Studio, or llama.cpp — with a local model for the agent and the judge, nothing leaves the machine. Unlike the closed Grok Bot, dots, Claude Duet, and Claude Tag it is modeled on, it runs where you put it, with the model you choose, and your data stays on your machine in each bot's folder.

### gemini-api-cli
- Details: Gemini API CLI is Google's experimental, Apache-2.0-licensed command-line interface for the Gemini API, built so coding agents and shell scripts can use Gemini models without a chat UI. Give Codex, Claude Code, Antigravity, OpenClaw, Hermes, or any other agent with shell access an API key, put gemini-api on PATH, and the agent can choose a model, generate an image, analyze a file, or launch a managed agent in the background and retrieve the result later with the returned interaction ID. One binary covers text and reasoning models, multimodal file analysis, and image, audio, music, and video generation, with script-friendly output (structured JSON or compact TOON, inline --jq filtering), a self-describing interface (--schema, --usage), and a --dry-run mode that validates inputs and prints the resolved HTTP request with credentials redacted. It is a single Go binary for macOS, Linux, and Windows, and each invocation is stateless, so the calling agent supplies the context and controls the next step.

### vals-ai
- Details: Vals AI is an independent AI benchmarking site that tests leading models on economically valuable real-world tasks — finance, software, cybersecurity, and frontier-risk areas such as recursive self-improvement and mental health — running its own evaluations and building many of its benchmarks in-house rather than relying on static Q&A. Its Vals Index leaderboards rank models per task area, with per-model pages comparing index scores alongside cyber, finance, legal, science, and code-migration sub-scores, token prices, and speed, and it publishes dated benchmark reports (such as its Nov 24, 2026 Swarm Speed study on multi-agent team efficiency). Scores are Vals' own harness snapshots and change as models are re-run, and index versions differ between pages, so small gaps between models should not be treated as exact.
