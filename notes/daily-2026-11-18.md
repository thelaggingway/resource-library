### 2. ADEMark
- URL: https://ademark.dev/
- Posted by: thelaggingway, 17 Nov

### 3. dsk
- URL: https://github.com/asx8678/dsk
- Posted by: asx, 17 Nov
- Category: dev-tool, github
- Brief: dsk is a small headless CLI and Claude Code plugin that hands the hands-on work — scouting code, writing it, running checks and web research — to cheap DeepSeek V4.1 Flash while Claude plans, reviews and decides. Runs route across your providers with failover, nothing lands unreviewed, and each request extends the previous one byte for byte so most input is a cache hit.

### 4. pi-emphasis
- URL: https://github.com/johnlindquist/pi-emphasis
- Posted by: asx, 17 Nov
- Category: dev-tool, github
- Brief: pi-emphasis is a Pi extension that turns [[Done]], [[Failed]] and [[Needs you]] into colored status pills with icons in assistant replies, so long answers are easy to scan. It also gives headings and lead labels icons and colors bold text, costs nothing to run, and needs only a Nerd Font terminal and Pi 1.5 or newer; MIT-licensed, 196 stars.

### 5. Agent Substrate
- URL: https://github.com/agent-substrate/substrate
- Posted by: ROman, 18 Nov
- Category: ai-tool, dev-tool, github
- Brief: Agent Substrate is a zero-trust runtime for running millions of sandboxed agents on Kubernetes, isolating each agent in a microVM or gVisor sandbox with its own identity, storage and default-deny networking, and resuming idle agents from snapshots in under 500 ms — about 250 stateful actors multiplexed onto 8 pods at 10x the density of plain containers. It is framework-agnostic, runs any OCI image, and reached 1.0; Apache-2.0, 7,359 stars.
