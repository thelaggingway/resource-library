## Details

### openui-live-replies
- Details: OpenUI Live Replies is a plugin for the bb coding agent that renders agent replies as interactive UI inside the chat thread. Agents emit OpenUI Lang programs in fenced code blocks and the plugin draws them with OpenUI's React component library plus about 70 of its own components, covering gauges, sparklines, heatmaps and funnels, timelines, calendars, roadmaps and kanban boards, trees, JSON explorers and diffs, test, lint, coverage, CI and benchmark reports, maps and small sandboxed apps. Plans, decisions, choices, quizzes and forms send the user's answer back into the thread as the next message, and components for bb itself show the thread's changed files, commits, pull request and the live status of other threads. It needs BB 0.49 or later, adds about 3,000 tokens of instructions to sessions whose replies are read, and needs no OpenUI Gateway or API key; web lookups are on by default, so Map and ImageSearch fetch from OpenStreetMap, Photon, Wikipedia and Wikimedia Commons unless turned off.
