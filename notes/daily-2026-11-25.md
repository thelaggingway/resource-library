### 1. Gemini Frontend Design
- URL: https://github.com/google-gemini/demolab
- Posted by: Alp, 25 Nov
- Category: ai-tool, github
- Brief: An agent skill from Google's Gemini team that teaches coding agents to build fast, clean landing pages with Gemini 4 Neon, built around five anti-slop rules — full-bleed display type, at most two font families, subject-matched colour palettes, custom Nano Banana visuals, and no pill badges, eyebrow kickers or nested cards. Install it with `npx skills add https://github.com/google-gemini/demolab --skill gemini-frontend-design` and it works with any agent that supports the open Agent Skills format, including Claude Code, Cursor and Gemini CLI.
- Warning: experimental skill in a Google demo lab repo, not a stable release; the repo contents may change.

### 2. BlackBox Arena
- URL: https://blackboxarena.ai/
- Posted by: scarywood75, 24 Nov
- Category: ai-tool, web-app
- Brief: BlackBox Arena (BB Arena) is an AI security benchmarking site that tests models across 100 black-box web and API security labs using a four-rung proof ladder and a single neutral harness. Alongside model leaderboards, it also publishes side-by-side provider comparison boards (such as DeepSeek V4.1 Flash) tracking solve rate, speed, timeouts, tokens, and cost per solve.
