## Details

### boxlite
- Details: BoxLite is a managed cloud runtime for AI agents built on hardware-isolated microVMs, each with its own Linux kernel: give your agent compute, networking, a domain, a filesystem and persistent storage, not just a sandbox. Boxes boot in milliseconds, survive restarts with around 10 GiB of disk, and can be published so every service port gets a public URL, with outbound traffic optionally pinned to an allowlist. You control it through an SDK or a REST API (104 endpoints) with an API key, and the same runtime is open-source under Apache 2.0 for self-hosting on your own machines. Pricing is pay-as-you-go from a prepaid wallet, or plans from $5/month (Starter, $20 included quota) to $100/month (Team, $400 included quota); boxes are priced per hour and larger plans raise the caps on box count, size and concurrency.

### redis-iris
- Details: Redis Iris is Redis's unified, real-time engine for agent context, combining six capabilities in one system: Intent Router matches the meaning behind a question to the right resource so the same intent is never recomputed twice; Agent Playbooks reuses stable answers and repeatable procedures to cut cost and raise accuracy; Agent Memory provides short-term working memory plus persistent context across conversations; Context Gateway exposes every context source through a single MCP endpoint; Lens turns agent behaviour into a queryable record of decisions for debugging and cost control; and Agent Mesh keeps agent streams alive across dropped connections. The pitch is that agents fail without the right context at the right time, and Iris supplies memory, routing and observability as one managed layer on top of Redis. Pricing is not shown on the page, so check Redis's sales or cloud pricing before budgeting.

### elephant-goldfish-model
- Details: The Elephant-Goldfish Model (EGM) is an open-source plugin for AI assistants that separates drafting a plan from reviewing it: you develop the plan with a drafting assistant that knows your goal, background and the whole conversation, then fresh reviewers who never saw the conversation read only the written plan and report what is missing or unclear. The point is that an author always knows things the plan does not say, and reviewers starting from zero catch those gaps — the worked example shows a study-space plan that never states who staffs the desk, when it is open, or what "the Friday rule" is. EGM runs as a plugin in supported AI assistant apps with no coding required, and review support differs between applications; the method comes from Dave Rensin's article "Elephants, Goldfish, and the New Golden Age of Software Engineering". The source is on GitHub, linked from the install guide on egm.dev.
