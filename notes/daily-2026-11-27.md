## Week: 19–26 Nov 2026

### 1. Paradev
- URL: https://paradev.com/
- Posted by: thelaggingway, 26 Nov
- Category: ai-tool, dev-tool
- Brief: Paradev (formerly Superset) is an open-source workspace for running coding agents — Claude Code, Codex, OpenCode and others — in parallel, each in its own isolated worktree, with a shared view for review. It ships macOS and Linux desktop apps plus mobile apps, automations, a plugin system, and cloud hosting in beta, so a team can orchestrate dozens of agents from one place.
- Warning: cloud hosting is in beta; Pro is a paid tier.

### 2. PERF-GS
- URL: https://electronicarts.github.io/perf-gs/
- Posted by: Alp, 26 Nov
- Category: ai-tool, web-app
- Brief: Electronic Arts' PERF-GS trains 3D Gaussian Splatting scenes in about ten seconds on a consumer GPU, with a dependency-free, cross-vendor trainer that keeps VRAM use low. The project page walks through the trainer design with real-time training videos and measured reconstructions, and links the code for running it yourself.
- Warning: the ~10-second training figures are EA's own measurements on an RTX 4090; results vary by GPU and scene.

### 3. opengame
- URL: https://github.com/nexu-io/opengame
- Posted by: thelaggingway, 26 Nov
- Category: ai-tool, github
- Brief: opengame is a "Super Game Agent" framework that turns coding agents (Claude Code, Codex, DeepSeek and others) into a full-stack AI game studio, with 100+ viral games to remix. It builds and publishes 3D and mini-games to WeChat, Douyin, TikTok, Telegram, itch.io and more from text prompts.

### 4. Supermemory
- URL: https://supermemory.ai/
- Posted by: baanish, 26 Nov
- Category: ai-tool, dev-tool
- Brief: Supermemory is a memory and continual-learning layer for AI agents — it turns raw conversation and document context into long-horizon knowledge with hybrid retrieval, extractors and connectors, exposed via API and MCP. It reports top scores on LongMemEval, LoCoMo and ConvoMem, with a free tier to start building.
- Warning: benchmark rankings are vendor-reported and unverified.

### 5. Ornn Data
- URL: https://data.ornn.com/analytics
- Posted by: thelaggingway, 26 Nov
- Category: ai-tool, web-app
- Brief: Ornn Data publishes market data and price indices for AI compute — GPU rental prices, token prices, memory spot prices and wholesale power — settled daily from real transacted deals rather than posted rate cards. The analytics hub lists every dataset it tracks, with free daily indices for six GPUs and token labs, and its compute index is listed on Bloomberg.
- Warning: full history, forward curves and most datasets need a paid plan; index values settle once daily and move with the market.

## Providers

### 6. OpenKodo
- URL: https://openkodo.dev/
- Posted by: thelaggingway, 26 Nov
- Category: providers
- Brief: OpenKodo is a $9.9/month coding-agent subscription that puts 79 frontier models from seven vendors — OpenAI, Anthropic, DeepSeek, Zhipu, Moonshot, Qwen and MiniMax — behind one key, with Responses, Chat and Anthropic-compatible APIs at a vendor-stated 200+ tokens/sec. It also bundles video models (Seedance, Kling, Vidu) billed per second, and works with Codex, OpenCode, Claude Code, Cline and other agents.
- Warning: third-party reseller subscription, not a direct vendor plan — no zero-data-retention assurances were stated (per the channel discussion); usage limits are vendor-stated estimates.
