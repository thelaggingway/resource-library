### 1. a2ui

- Posted by: ROman, 22 Nov
- Category: ai-tool, github
- Brief: a2ui is an open-source generative UI framework for AI agents: agents stream layout data and apps render it with native components instead of screenshots or HTML. ### 2. wland
- URL: https://github.com/pithings/wland
- Posted by: simply_roo, 22 Nov
- Category: dev-tool, github
- Brief: wland is an open-source Wayland compositor that runs entirely in the browser, written in Zig and compiled to WebAssembly at roughly 65 kB gzipped. It composites Wayland apps at up to 120 FPS with pixel-perfect Retina rendering, so native Linux GUI apps can run inside a web page with no server.
