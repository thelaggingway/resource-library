### datalix
- Details: Datalix is a German hosting provider selling prepaid Xeon KVM servers from €2.45/month in its 2026 sale, hosted in Frankfurt datacenters (Equinix FRA-07, FRA-05, FRA-08 or Cogent). Servers come with full root access, NVMe storage, a choice of OS images including Windows, and AS203446 SmartMitigate DDoS protection, and are online within 60 seconds of payment. Its in-house control panel covers backups, ISO mounting, a noVNC console, SSH keys, traffic and DDoS logs, and one-click upgrades to more cores, RAM, disk or IPv4 addresses. Everything is prepaid with no contract — servers lock at the end of the term and are deleted after 5 days — and support runs 09:00–22:00, usually replying within an hour. The €2.45/month entry price is a 2026 sale offer, so it may not last beyond the sale.

### ademark
- Details: ADEMark is an open benchmark that measures agentic dev environments — the apps you run coding agents in — side by side on a single Mac mini M4 with 16 GB, against plain Claude Code in a terminal (the Bare CLI) as control. Its first results, from a run ending 12 November 2026, rank 14 ADEs across 12 tests covering cold start, relaunch, thread opening, typing lag, memory and CPU at rest and under load, tokens per hello, and a multi-agent build test. There is no overall winner by design — each test is ranked on its own — but super.engineering leads 4 of the 12 tests, Synara passes the build test fastest at 5.2 minutes, and the terminal still launches fastest at 0.69 seconds cold start. All apps ran as shipped with no added skills or plugins, and the method, including where the harness itself caused gaps, is published on the page.

### dsk
- Details: dsk is a small headless CLI and Claude Code plugin that lets Claude Code hand the hands-on work — scouting code, writing it, running checks and web research — to cheap DeepSeek V4.1 Flash while Claude plans, reviews and decides. It is written in TypeScript with no dependencies, runs its worker scripts in Python, and installs as its own Claude Code marketplace with plugin install dsk --marketplace asx8678/dsk. Runs route across your providers — DeepSeek's own API or any OpenAI-compatible endpoint serving a DeepSeek model — with automatic failover, and every run is measured rather than claimed: only the summary, answer, notes and question are the worker's words, the rest is measured by dsk. Nothing lands unreviewed: dsk runs every check itself, undoes changes outside the allowed scope, and a Stop hook sends Claude back to sessions still waiting for accept or reject. Costs stay low because each request extends the previous one byte for byte, so most input is a cache hit.

### pi-emphasis
- Details: pi-emphasis is a Pi extension by John Lindquist that makes assistant replies scannable: it turns [[Done]], [[Failed]] and [[Needs you]] into colored pills with icons, gives headings and lead labels icons from their word, and colors bold text, arrows and tree lines. It changes only what is drawn — stored messages, copied text and HTML exports keep the original Markdown — and it calls no model and costs nothing to run. The extension also adds a reply-style section to Pi's system prompt so the agent writes pills in the first place, using the same word tables that color them, adding about 1,500 tokens per run. It needs Pi 1.5 or newer and a terminal that can draw Nerd Font symbols (Ghostty, kitty and WezTerm include them); without those, icons and rounded ends can be turned off. Install with pi install git:github.com/johnlindquist/pi-emphasis. MIT-licensed; checked on macOS only.

### agent-substrate
- Details: Agent Substrate is a security-hardened, zero-trust runtime for sandboxed agents on Kubernetes, built to run millions of agents and tools at 10x the density of standard containers. Every agent (actor) runs inside a dedicated gVisor or Cloud Hypervisor microVM sandbox with segregated compute, network and storage — plain Linux containers are not supported — and gets a short-lived SPIFFE identity, while a built-in egress gateway injects credentials into approved outbound requests outside the sandbox so a compromised agent has nothing to exfiltrate. Because agents spend most of their lives waiting, Substrate snapshots idle actors out of memory and resumes them in under 500 ms, multiplexing roughly 250 stateful actors onto 8 worker pods with over 500 activations per second. It is framework-agnostic — ADK, LangChain, Claude Code, Codex, MCP servers — runs standard OCI images on Kubernetes with Pods, autoscaling and NetworkPolicies, and has reached 1.0. Apache-2.0 licensed, 7,359 stars.

### alysis-code
- Details: Alysis Code is a coding agent for desktop and CLI, built on an open-source engine, that runs on your choice of 16 models — including DeepSeek V4.1 Flash, GLM 5.3, GPT-6 Luna, Claude Haiku 5.5, Kimi K3 and Claude Sonnet 5.5 — either on Alysis credits or free with your own API key or a local model. Every account gets 50 free credits (up to $0.50 of usage) on 4 small, fast models; paid plans add more — Beta 100 credits on 7 models, Alpha 500 credits on 12 models including larger ones plus 50 cloud credits, Pro 1,500 credits on all 16 models plus 200 cloud credits — with cloud computers billed at 25 credits per running hour. Credits renew every 30 days and unused credits expire; requests pause when credits run out unless you switch to your own key or a local model.
