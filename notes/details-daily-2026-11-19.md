## Details

### oss-new
- Details: oss.new is a tool that clones software products as open-source apps. You paste a link to any app, it studies what the product does, and then builds an open-source version that runs on Cloudflare. The result installs on your own EveryApp Gateway, or you can copy the code to your GitHub and run it yourself. It is aimed at developers who want a self-hosted, open alternative to a closed product without rebuilding it from scratch.

### energy-based-reasoners
- Details: Energy-Based Reasoners is a research paper by Chen, Gladstone, Li, Ji and Du (arXiv:2611.08977, submitted 6 November 2026) that rethinks looped reasoning models. Looped models iterate a recurrent block to scale their effective depth, but they have no built-in sense of progress, so they cannot tell when to stop or how to improve. EBRs learn an energy function over latent reasoning states and treat each looped update as gradient descent on that energy, so the energy scores states, its gradient guides refinement, and the score gives a natural stopping signal. Across four algorithmic reasoning benchmarks the method matches or beats prior recurrent models, reaching 99.9 percent accuracy on Sudoku-Extreme with 345 times less inference compute than the next-best model and state-of-the-art coverage of distinct valid solutions. The project site is energy-based-reasoners.github.io and the code is at github.com/wwillchen/ebr.

### distortion-waves
- Details: Distortion Waves is a free, MIT-licensed screen-transition library for React and SwiftUI by Jakub Antalik. It carries one view into another on a colourful wave that opens from the element that started it, a button, screen edge or avatar, bending the outgoing view with edge glows, chromatic aberration, blur, particles and an anticipation pull before the new view settles. The React package installs with npm install distortion-waves and needs React 18 and WebGL2; the SwiftUI kit ships as DistortionWavesKit via Swift Package Manager for iOS 17 and up. Three wave types (vertical, horizontal, centre) and six palettes cover common transitions, and the wave can be driven imperatively with play, reverse, reset and scrub controls. It is a distinct library from the same author's published Liquid Gooey, which lives on the same libraries.dev hub.

### metaphor
- Details: Metaphor is a cloud coding agent: you start coding tasks in a cloud workspace and the agent works through them while you review each change line by line, edit files in a built-in editor, and run commands in a dedicated terminal. It pitches itself as the most cost-efficient cloud coding agent, claiming to run about 30 percent cheaper than Codex and Claude Code with around 95 percent cache token consumption and a 93.7 percent cache hit rate; those cost figures are vendor-reported and unverified. Pricing is subscription-based on Metacloud minutes: the Hacker plan is $4.80 a month with 6,000 minutes and the Pro plan is $20 a month with up to 60,000 minutes, while the free tier is shown as temporarily paused. A mobile app is coming soon and Linux support is waitlisted.

### nous-portal
- Details: Nous Portal is the inference portal run by Nous Research, giving API access to a large catalogue of frontier and open models through one account. The catalogue spans Anthropic Claude, OpenAI GPT, Google Gemini, DeepSeek, Qwen, Kimi, Mistral, Meta Llama and many smaller labs, each listed with published per-token input and output prices and a batch-pricing tier alongside standard rates. The portal is pay-as-you-go on credits, so it suits developers who want to try or route across many models without opening an account with each provider. The shared post announced Qwen 4 Max free on the portal for five days from 19 November, so that particular offer is time-limited.
