## Details

### gemini-frontend-design
- Details: DemoLab is Google Gemini team's library of creative, frontend and experimental agent skills, and gemini-frontend-design is its first skill: a SKILL.md that steers a coding agent to design polished websites and web apps with a clear visual point of view, a first screen matched to the page's purpose, and typography, proportion, color, imagery and motion doing the work instead of decorative chrome. It was drafted to get the best out of Gemini 4 models for frontend design, and the team's evaluations found users preferred designs made with the skill 67 percent of the time over no skill and 75 percent of the time over popular third-party frontend design skills. The skill's five rules are a full-bleed hero, at most two font families with three body sizes, a subject-matched palette that avoids default beige and purple, custom Nano Banana visuals with clean contrast, and no pill badges, eyebrow kickers or nested cards. Install it with npx skills add google-gemini/demolab --skill gemini-frontend-design; it works with any agent that supports the open Agent Skills format, and the skill is Apache-2.0 licensed.

### blackbox-arena
- Details: BlackBox Arena (BB Arena) is a black-box benchmarking platform that evaluates AI models across 100 web and API security labs using a four-rung proof ladder and a single neutral harness. Rather than relying on static Q&A, each lab tests whether a model can make real progress through practical security tasks, reporting solve rates, rungs reached, timeout shares, speed, throughput, latency, token usage, and cost. Alongside its main model rankings and methodology documentation, the site publishes provider comparison boards — such as its DeepSeek V4.1 Flash board — that run API providers through the same subset of labs (10 labs, 40 attempts, 25-minute limit per attempt) to expose differences in actual solve rate and cost per solve across hosts serving the same model. The numbers are BB Arena's own harness snapshots and change as models and providers are re-run, so treat rankings and listed prices as current-as-shown rather than independently verified.
