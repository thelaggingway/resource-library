## Details

### a2ui
- Details: A2UI is an open-source generative UI framework and protocol for agentic experiences: instead of an agent replying in text alone, it streams structured UI data that native renderers turn into real widgets. The data-not-code approach keeps a strict schema between agent and renderer, so agent-generated interfaces stay within the app's capability boundaries. It ships agent SDKs in several languages, a versioned protocol spec, native renderers for React, Angular, Lit, Flutter, SwiftUI and Jetpack Compose, plus a browser-based A2UI Composer for trying compositions. It fits apps where an agent should build the flow itself — remote rendering is supported by design, and the same agent can drive UI across web and mobile without WebViews or HTML.

### wland
- Details: wland is a Wayland compositor compiled to WebAssembly (about 65 kB gzipped) that runs in a browser tab. Unmodified Wayland apps — foot, Nautilus, Chromium, even X11 apps via xwayland-satellite — talk the real wire protocol to a small relay (wlandr) on a Linux host, VM or container, which streams them over WebSocket or vsock to the compositor; typing, menus, clipboard, drag and drop, HiDPI and window controls all work, at up to 120 FPS on a Retina MacBook. A Docker demo image runs Chromium and a file manager in the page, and an npx CLI serves your own machine's apps. Note it is brand-new, announced 21 Nov 2026, so expect rough edges — the README lists known limits.

### building-a-customised-second-brain-for-a-diplomat-in-claude-duet
- Details: A full recipe for a curated, source-checked "second brain" built on Claude Duet, written by Singapore Foreign Minister Vivian Balakrishnan after running a similar NanoClaw agent on a Raspberry Pi for nine months. The setup gives Claude a private wiki of Markdown pages distilled from the principal's own sources (speeches, statements, treaties), a short primer stating the principal's framing, and a strict order of authority — primer first, wiki second, web third — with every claim checked against its source file and disagreements shown, never hidden. It works by instructions alone: a folder of Markdown files in a private repo, one skill and two small scripts, with no server, vector database or embeddings, and each question runs in its own Duet thread that clones the repo and compiles a brief before answering. The actual knowledge base and sources are private and not included; the gist is the generic method, a worked example (a High Seas Treaty wiki page) and step-by-step setup.

### privacy-notice-regarding-minimax-requests-on-novita
- Details: Novita confirms that, after a report from an independent security researcher, it found some MiniMax requests were forwarded to MiniMax's official API instead of being processed on Novita-hosted infrastructure. A routing configuration issue meant an API forwarding path intended for specific customers applied more broadly; the affected models were suspended. Anyone who used MiniMax models through Novita (directly or via OpenRouter) between 28 May and 11 November 2026 should assume request contents may have been accessed or retained by a third party, and rotate any live credentials or secrets included in those requests. Novita says it does not retain customer prompts or outputs or use them for training, and is verifying the affected endpoints and following up with MiniMax about deletion of retained data.
