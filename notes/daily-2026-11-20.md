## Week: 12–19 Nov 2026

### 1. BoxLite
- URL: https://boxlite.ai/
- Posted by: ROman, 19 Nov
- Category: ai-tool, dev-tool
- Brief: BoxLite is a managed cloud for AI agents that runs your app in hardware-isolated microVMs with compute, networking, a domain, a filesystem and persistent volumes, giving each box a public URL to share. You drive it from an SDK or REST API, pay as you go from a prepaid wallet or take a plan from $5/month, and the same runtime is open-source (Apache 2.0) for self-hosting.

### 2. Redis Iris
- URL: https://redis.io/iris/
- Posted by: ROman, 19 Nov
- Category: ai-tool, dev-tool
- Brief: Redis Iris is Redis's real-time engine for giving AI agents the memory, context and messaging they need, bundling six capabilities — Intent Router, Agent Playbooks, Agent Memory, Context Gateway, Lens and Agent Mesh — into one system. It routes questions by meaning, reuses stable answers, keeps short- and long-term agent memory, exposes context over a single MCP endpoint, and records every agent decision for diagnosis.

## Week: 19–26 Nov 2026

### 3. Elephant-Goldfish Model
- URL: https://egm.dev/
- Posted by: ROman, 20 Nov
- Category: ai-tool, dev-tool
- Brief: The Elephant-Goldfish Model (EGM) is an open-source plugin for AI assistants that splits plan drafting from plan review: one assistant that knows the full background helps you write the plan, then fresh reviewers who never saw the conversation read only the plan and report what is missing or unclear. It runs in supported AI assistant apps with no coding needed, and the method comes from Dave Rensin's "Elephants, Goldfish, and the New Golden Age of Software Engineering".
