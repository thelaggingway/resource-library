## Details

### paradev
- Details: Paradev (formerly Superset) is an open-source workspace for orchestrating coding agents. It runs Claude Code, Codex, OpenCode and other agents in parallel, each in its own isolated worktree on a separate branch, and shows every agent's work in one review surface with a command palette and Linear and PR automation. Desktop apps for macOS and Linux, mobile apps for iOS and Android, automations that trigger on events, a plugin system that works across agents, and cloud workspaces in beta, plus remote hosts. The project page reports 16.8k GitHub stars and a recent $11.5M seed round. The core workspace is MIT-licensed open source; Pro is a paid tier with cloud hosting.

### perf-gs
- Details: PERF-GS is Electronic Arts' research project for ultrafast 3D Gaussian Splatting training. The Ultrafast preset trains a scene in about 10 seconds on an RTX 4090, with a Quality preset at about 23 seconds and Quality+ at about 123 seconds for higher PSNR — all EA's own measurements, so treat them as indicative rather than exact. The trainer is dependency-free, cross-vendor and low-VRAM, built on SlangPy for GPU dispatch, and the page documents the design (initialization, forward and backward passes, densification) with real-time training videos and held-out reconstructions across the nine-scene Mip-NeRF 360 dataset. You can run COLMAP on your own photos in the PERF-GS hub or open an existing scene, then train and explore the result; code is linked from the page.

### opengame
- Details: opengame is an open-source framework that turns coding agents into a game studio. Point Claude Code, Codex, DeepSeek or 20+ other agents at it and it builds 3D and mini-games, with 100+ viral games included to remix. Games publish to WeChat, Douyin, TikTok, Telegram, itch.io and more, and the pitch is text-to-game with multiplayer and instant play — positioned as the Unity and Unreal for AI agents. The repo is the whole product: agent orchestration, game templates and publishing targets in one place.

### supermemory
- Details: Supermemory is a hosted memory layer for AI agents. It ingests conversation and documents through connectors and extractors, then builds long-horizon knowledge with hybrid retrieval and reranking, exposed through an API and an MCP server so agents can recall and update memories across sessions. The team reports top scores on the LongMemEval, LoCoMo and ConvoMem benchmarks (vendor-reported, unverified) and says the system serves over a trillion tokens a month in production, with a free tier to start. It is pitched as the memory system agents need for personalization and self-improvement over long tasks.

### ornn-data
- Details: Ornn Data tracks AI compute markets: GPU rental prices, model token prices, memory spot prices and wholesale power, settled daily from real transacted deals and published as price indices. The free daily indices cover six GPUs (H100 SXM, H200, B200, B300, A100 SXM4, RTX PRO 6000) plus token labs, with the H100 SXM index at $3.10 per GPU-hour as settled November 25, 2026 (vendor-reported; the value moves daily). Full history, forward curves, occupancy, payback and depreciation data need a paid plan. The Ornn Compute Price Index is listed on Bloomberg and used for pricing, hedging and settlement across the compute market.

### openkodo
- Details: OpenKodo is a $9.9-per-month subscription (up to $100 of usage included) that gives coding agents one API key for 79 models across seven vendors — OpenAI, Anthropic, DeepSeek, Zhipu, Moonshot, Qwen and MiniMax — through Responses, Chat and Anthropic-compatible endpoints, at a vendor-stated 200+ tokens per second. It lists current frontier models (Claude Opus 5.5, GPT 6.2 Astra, DeepSeek V4.1, GLM-5.3), compares itself directly with OpenCode Go ($10/month) on requests per 5-hour window (vendor-reported comparison), and adds video models such as Seedance, Kling and Vidu billed per second. It works with Codex, OpenCode, Claude Code, Cline, Continue, Cursor and Aider. The first month is $4.90 with an invite code, and it is a third-party reseller rather than a direct vendor plan.
