## Details

### designbookmark-motion
- Details: DesignBookmark Motion is a gallery of animated UI components that run live in the browser, so you can see exactly how each motion feels before using it. The collection covers dozens of patterns — spring dropdowns, morph tooltips, jelly sliders, swipe decks, parallax tickets, glass lenses, pull-to-refresh, scramble text and more — each with copyable code for Claude or Codex. You pick a component, paste it into your project, and your AI coder builds it for you, which makes it a fast way to add polish to vibe-coded sites that otherwise look flat. The Motion page is free to browse with no account.

### pi-better
- Details: pi-better is a Pi extension by Nico Bailon that rewrites your prompts before you send them. Type /better in front of a prompt and a forked subagent reads your code, files, docs and logs in the background, then applies Felix Rieseberg's "Depth" prompt — what a top professional would do that you didn't ask for, the rawest material to start from, the specific methods and tools, and an independent check of the result — to produce a sharper prompt grounded in your actual project. The improved prompt lands in your input box for review, nothing is sent until you press Enter, and your agent can use it on subagent briefs too via pi-subagents. It installs with pi install npm:pi-better, is MIT licensed, and had 104 stars within a week of its 8 Nov 2026 release.

### baum
- Details: baum is a desktop app for keeping up with what your coding agents build. It reviews the pull requests in your GitHub repositories, ranks them by risk, and explains each one by the parts that need you rather than a line-by-line diff, while a sessions view shows which Claude Code and Codex sessions are waiting on you and a timeline groups PRs into features with the decisions made along the way. A decision log traces the reasoning from the agent session behind any piece of code, and a usage view shows how much of your Claude and Codex plans is left. It runs entirely on your computer with no baum account or server — reviews run through your own Claude Code or Codex — and it is MIT licensed with desktop builds for macOS and Linux.

### yab
- Details: Yab is a fast native macOS browser, now fully open source under Apache-2.0, with iPhone and Android companions, pitched as the best Arc alternative. It keeps a single field for addresses and searches, tabs across the top or down the left with pins, folders and spaces, and pages running on WebKit by default or Chromium per tab on Apple silicon, with Chrome extensions and DevTools where needed. Built in are an ad blocker, element hiding, reading mode, floating video, split view and Peek, plus agents that work in their own tabs with your sign-ins and ask before they send, pay or delete anything. Sync between Macs and iPhone is optional and end-to-end encrypted, and the repo had 336 stars within two days of its 14 Nov 2026 open-sourcing.
